# Security reporting

Please do not publish suspected vulnerabilities, encryption recovery keys, tokens, or private notes in a public issue.

Email **random1k11@gmail.com** with subject **Vaulto Note security report**. Include the affected version, platform, a minimal reproduction using fictional data, and the expected security boundary. This address is the application's public Google Play support contact.

This project has not undergone an independent security audit. Source availability enables inspection; it does not certify the implementation or the official store binary. No response-time guarantee or bug bounty is currently offered.

Security-sensitive implementation and its limitations are described in [docs/PRIVACY.md](docs/PRIVACY.md). Please test on devices and accounts you control; do not probe other users' data or the production service without authorization.
