# Автоматическая обработка с сетью и без неё — 19 октября 2026

Изменения рабочего дерева после `af2adf5` / 1.0.93. Новая версия приложения
не собиралась и в Google Play в рамках этой проверки не отправлялась.

## Поведение

- С интернетом новые запросы используют выбранное облако.
- Без сети скачанный Whisper распознаёт записи, скачанный Qwen обрабатывает текст.
  Это независимые модели: скачивание только Whisper не включает локальные улучшения.
- После подключения новые запросы снова используют облако; готовые локальные
  результаты автоматически не переписываются и повторно не отправляются.
- «Только на телефоне» сохраняет локальную обработку и при наличии сети.
  Защищённые заметки сохраняют отдельный запрет облачной обработки.
- Если модели распознавания нет, запись сохраняется для последующего распознавания
  с интернетом. Возобновление действует при открытой/повторно открытой заметке;
  фоновый запуск при закрытом приложении не обещается.

Базовый выбор по сети уже был в 1.0.93. Здесь добавлен подхват скачанным Whisper
при транспортной ошибке/таймауте **после** начальной проверки сети. Выбор облака
не меняется. Ошибки HTTP 400/422/500 не маскируются этим подхватом.
Для текстового ИИ проверяется выбор маршрута перед новым запросом; повтор
прерванного облачного запроса к текстовому ИИ здесь не добавлялся.

## Понятность интерфейса

«Офлайн-режим» переименован в **«Работа без интернета»**: переключатель управляет
скачиванием моделей, а не принудительным выбором локальной обработки. Подтверждения
теперь спрашивают «Скачать модели?» / «Удалить скачанные модели?».
Настройки кратко объясняют автоматическое переключение и передачу выбранного
ввода облачному сервису. Индикатор показывает «Распознаю в облаке…» или
«Распознаю на телефоне…». При выборе маленького ИИ показано предупреждение
о возможных пропусках деталей и ошибках в фактах. Изменения переведены на 10 языков.

## Проверка

Android 16 / API 36, эмулятор `vaulto_recovery_qa2_20261018` (`emulator-5560`),
около 2.59 GB RAM, Whisper Base + Qwen3.5 0.8B. Debug-клиент с актуальным кодом
через Metro. Во всех трёх прогонах сохранены `vaulto_ai` и выключенное
«Только на телефоне». Использован один искусственный русский аудиофайл 12.038 s,
переданный через настоящий Android Files → Share.

| Сценарий | Результат |
| --- | --- |
| Wi-Fi/data включены | Реальный облачный текст, 149 символов; облачная подпись индикатора |
| Wi-Fi/data выключены | Реальный Whisper Base, 145 символов; локальная подпись индикатора |
| Wi-Fi/data снова включены | Снова облачный текст, 149 символов, без ручного выбора режима |
| Текст `Buy milk.`, без сети, облако по-прежнему выбрано | Реальный Qwen извлёк одну задачу `Buy milk`, без добавленной даты/времени |
| Отмена удаления моделей | Понятное подтверждение; модели и включённая работа без интернета сохранены |

Транскрипции проверены в интерфейсе, сохранение настройки — в SQLite AsyncStorage;
каждая новая подпись аудиозаписи сохранена как шифротекст `v3d.`.
Полные синтетические результаты и скриншоты:
[results.json](qa/2026-10-19/network-routing/results.json),
[настройки](qa/2026-10-19/network-routing/settings-auto-ru-final.png),
[выбор моделей](qa/2026-10-19/network-routing/models-auto-ru.png).

`npm test` прошёл. Итоговый набор `test:voice-workflow` — **15/15**:
включая online→offline→online, обрыв после проверки сети, таймаут, транспортный
сбой Custom AI, отсутствие модели, запрет облака для защищённого аудио и
возврат текстового ИИ к выбранному облаку. Обрывы/таймауты проверены управляемыми
ошибками на границе fetch, а не имитацией реального обрыва уже идущей передачи
на эмуляторе. Итоговый typecheck и `git diff --check` прошли. Проверены семь
изменённых строк/ключей в каждом из 10 языков; прежние значения и различия
множественных форм сохранены.

Локальный Whisper в этом примере ошибся в имени Анны и слове «пятницу»;
успешный переход не означает одинаковое качество локальной и облачной модели.
Семантические ограничения маленького Qwen из предыдущего QA остаются.
Физический телефон, скорость/нагрев/батарея и качество облачных улучшений
для вошедшего аккаунта этой проверкой не подтверждены.
