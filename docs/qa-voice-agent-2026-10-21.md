  после исчерпания его AI-квоты вход `claude-e2e-auto-1791057092` (ключ восстановления через QR).

  Хук удалён, `AudioService.ts` и `VoiceRecorder.tsx` совпадают с HEAD.
- Пачка из 15 фраз также отправлена прямо в `POST /ai/agent`, чтобы оценить решения агента.
- Живой микрофон, физический телефон и офлайн-модели в этом проходе не проверялись.

## Агентский режим: включён ли по умолчанию

Отдельного переключателя нет (убран в 1.0.91). Маршрут выбирает
`resolveVoiceAgentRoute` в `src/services/voiceAgent.ts`:

| Пользователь | Что происходит с каждой записью |
| --- | --- |
| Вошёл, есть интернет | Всегда облачный агент: команды выполняются, обычная диктовка может сама превратиться в версию «Formatted»/«Checklist» |
| Гость без модели 2B+ | Агента нет: «Сделай из этого чек-лист» вставляется текстом, без подсказки |
| Приватный режим / офлайн / защищённая заметка | Агент на телефоне только с Qwen 2B/4B; с 0.8B — обычная диктовка |

## Не исправлено — нужно решение

1. **Бесплатная AI-квота расходуется на обычную диктовку.** План `free`: 50 000 LLM-токенов в месяц,
   агент тратит около 2.5 тыс. на запись, то есть примерно 20 голосовых заметок.
   После этого **каждая** запись показывает блокирующее окно «Usage Limit Reached… try again later»,
   хотя текст уже сохранён, а кнопки апгрейда нет (кнопка есть только для лимита минут).
   Варианты: не звать агента при известном нуле квоты; показывать окно один раз
   с предложением Pro; не тарифицировать диктовку без команды.
2. **Гость: агент молча выключен.** Команда становится текстом. Нужна подсказка
   «голосовые команды работают после входа» хотя бы при первой похожей фразе.
3. **Избыточная команда вставляется текстом.** «Сделай из этого чек-лист» для уже готового
   чек-листа: сервер отвечает `has_instruction=false`, фраза попадает в заметку.
   Нужна правка промпта в `claude_gateway_service/app/application/agents/ai_note_agent.py`:
   команда без изменений — `has_instruction=true`, `action=none`.
4. **Автоформат без спроса.** Обычная диктовка вошедшего пользователя иногда (не детерминированно)
   превращается в версию «Formatted»/«Checklist», и открывается именно она. Оригинал цел, но поведение
   неожиданно и непредсказуемо. Стоит решить, нужен ли автоформат и нужен ли для него переключатель.
5. **Точность фактов у `gpt-5.4-nano`.** «В пятницу отчёт» → «Перед пятницей…»;
   при «Сократи до трёх пунктов» «бюджет 150 тыс.» стал «150 тыс. на рекламу».
   «Summarize» вернул текст длиннее оригинала (767 против 591 символа) с ошибкой «ответственным Мариной».
6. **Мелочи UX.** Корзина в записи удаляет без подтверждения. Выключенный «To text» запоминается
   для всех следующих записей и отключает и текст, и агента. Добавленные голосом пункты пишутся
   строчными и без глагола («сыр» рядом с «Купить хлеб»). При трёх версиях вкладка «Formatted»
   обрезана. Онбординг обещает расшифровку без интернета, но по умолчанию модель не скачана.
   В меню доступности кнопок «назад» и «показать пароль» на входе вместо подписи глиф иконки.
