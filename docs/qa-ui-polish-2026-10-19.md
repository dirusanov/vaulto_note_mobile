# Повторная проверка удобства Android — 19 октября 2026

Проверено рабочее дерево после `af2adf5` / 1.0.93, включая предыдущие улучшения
автоматического выбора обработки. Новая подписанная сборка и отправка в Google
Play в рамках этой проверки не выполнялись. Это собственный QA, не пользовательское
исследование и не новый входящий отзыв.

## Найдено и исправлено

1. **Мало места для списка моделей при крупном шрифте.** На экране 900×1600,
   420 dpi и системном шрифте 200% неподвижное пояснение оставляло почти только
   заголовок списка. Пояснение теперь прокручивается вместе с моделями, заголовок
   переносится в пределах доступной ширины, кнопки закрытия и применения остаются
   доступны. Область нажатия крестика увеличена; названия и бейджи переносятся.
2. **Кнопки удаления уходили за экран.** Подтверждение удаления моделей на том же
   экране при шрифте 200% выходило за границы окна. Общий диалог теперь ограничен
   доступной высотой с учётом системных отступов, содержимое прокручивается,
   на узком экране/крупном шрифте действия стоят друг под другом. Кнопки могут
   увеличиваться по высоте; обе объявлены кнопками для средств доступности.
3. **Неточная подпись режима только речи.** Когда скачан Whisper, но нет Qwen,
   окно выбора моделей говорило, что голос **и ИИ** работают локально.
   Теперь в этом состоянии подпись говорит только о голосе. При наличии обеих
   моделей остаётся полная подпись про локальную обработку голоса и ИИ.

Дополнительно исправлено состояние неизменённого выбора «Только распознавание»:
показывается «Готово», вместо предложения применить тот же выбор. При повторном
открытии окна сбрасываются предыдущий план/выбор до завершения проверки моделей.
Ошибка получения списка перехватывается, предлагаются повтор и закрытие,
вместо бесконечного индикатора. Новая строка ошибки добавлена во все 10 языков,
прежние значения, включая параллельные изменения, сохранены.

## Нативные проверки

Android 16 / API 36, `emulator-5560` / `vaulto_recovery_qa2_20261018`.
Debug-клиент с текущим кодом через Metro. Основной экран 1080×2400, 420 dpi,
шрифт 100%; дополнительный 900×1600 со шрифтами 130% и 200%.
Русский/английский, светлая/тёмная темы.

**13 сценариев прошли:**

- Список моделей при 200%: прокрутка до Qwen, доступные крестик и «Готово».
- Диалог при 200%: прокрутка к обоим действиям, «Оставить» сохраняет модели.
- Только Whisper: точная подпись приватности, неизменённый выбор — «Готово».
- Другая модель: размер скачивания виден; закрытие окна отменяет неподтверждённый
  выбор, повторное открытие сохраняет выбранный Base.
- Обе модели: «Только на телефоне» включает голос и ИИ локально и сохраняется
  после force-stop/cold launch при доступном интернете. Проверены сохранённые
  `vaulto_ai_provider=local` и `vaulto_on_device_transcription=true`.
- Предупреждение тяжёлой модели: облако включается только явным нажатием
  «Use Vaulto cloud»; оба сохранённых параметра возвращаются к облачному режиму.
- Реальное скачивание Whisper Turbo: размер до начала, затем прогресс
  (`1 MB / 574 MB`), отмена, возврат готовности; Base и Qwen сохранены.
- Обычный шрифт/тёмная тема: полное подтверждение помещается в экран,
  оба действия видны, отмена сохраняет модели.
- Заметка с пятью производными версиями: Structure → Original возвращает точно
  прежний исходный текст; переключение не заменяет оригинал.
- Выбор версии → Compare with Original открывает сравнение в тёмной теме.
- Новый черновик с Unicode-заголовком, Markdown-заголовком, `[ ]`, `[x]`, жирной
  суммой и маркером сохраняется без выхода из редактора и переживает force-stop.
- Восстановленный черновик экспортируется реальным Markdown-файлом через системное
  меню Android. Получатель не выбирался, содержимое другой программе не отправлялось.
- В конце восстановлены 1080×2400, 420 dpi, шрифт 100%, русский язык и системная
  светлая тема. Base и Qwen по-прежнему выбраны, приватный режим выключен.

Для проверки «только Whisper» файл Qwen временно переименован при остановленном
приложении и восстановлен в `finally`; новый Qwen не скачивался. Исходный файл
532 517 120 байт восстановлен. Все заметки и текстовые примеры искусственные.

## Проверки кода и пределы результата

`npm test`, итоговый typecheck и `git diff --check` прошли. Для 10 переводов
проверено, что в этом проходе добавлен только ключ ошибки загрузки списка моделей.
Ошибку загрузки списка проверяли по коду; принудительное воспроизведение
исключения нативного модуля не выполнялось. Полный аудит TalkBack не проводился.

Это проверка конкретных экранов и сценариев, не гарантия удобства на любом
устройстве. Физические замеры скорости/нагрева/батареи и качество облачного
улучшения текста для вошедшего аккаунта здесь не проверялись. Ранее найденные
смысловые ошибки Qwen3.5 0.8B остаются ограничением модели; оригинальные замечания
F-01/F-03 не объявляются полностью исправленными. Для переходов сети см.
[предыдущий протокол](qa-network-routing-2026-10-19.md).
